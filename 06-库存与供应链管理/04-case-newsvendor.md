## 1 场景

你是一家医药零售连锁店的供应链经理。每个月你需要决定每种药品的补货量。仓库里存着 200 种药品，每种药品的需求是随机的（服从正态分布）。

你面临一个问题：**补货不是免费的**——每次下单都有固定订货成本 K（比如：运输费、质检费、系统处理费）。当 K>0 时，你就不应该「每次缺了就订」——而应该凑到某个量再订，一次多订点。

```
        需求随机波动        固定订货成本 K
           ↓                      ↓
   [供应商] ──订货──→ [仓库] ──→ [门店/患者]
                        ↑
                    持有成本 h / 缺货成本 p
```

你的任务是比较三种补货策略：

| 策略 | 规则 | 特点 |
|------|------|------|
| **(s,Q) 策略** | 库存低于 s 就订固定量 Q | 最简单，行业常用 |
| **(s,S) 策略** | 库存低于 s 就订到 S | 理论上更优，S = s + Q' |
| **最优 DP** | 用动态规划计算每个库存水平下的最优决策 | 理论最优，但计算复杂 |

### 教学点

- **固定订货成本 K > 0 时，(s,S) 是最优策略结构**——这是著名的 Scarf 1959 定理的结论
- 动态规划如何找到全局最优补货策略
- 仿真验证：理论最优策略在实际随机环境中是否真比 (s,Q) 好
- 报童逻辑在多期问题中的延伸——每期最优订货量 = 报童解 + 考虑未来

## 4 数学模型

### 4.1 库存动态方程

```
I_{t+1} = max(Iₜ + Qₜ - Dₜ, 0)
```

即：缺货不积压（lost sales 模型）。

### 4.2 单期成本函数

```
Cₜ(Iₜ, Qₜ, Dₜ) = K × 𝟙(Qₜ > 0) + c × Qₜ + h × max(Iₜ+Qₜ-Dₜ, 0) + p × max(Dₜ-Iₜ-Qₜ, 0)
```

其中 𝟙(Qₜ > 0) 指示是否发生订货。

### 4.3 (s,Q) 策略

```
if Iₜ ≤ s:
    Qₜ = Q        # 订固定量 Q
else:
    Qₜ = 0        # 不订货
```

参数 (s, Q) 通过仿真搜索优化。

### 4.4 (s,S) 策略

```
if Iₜ ≤ s:
    Qₜ = S - Iₜ   # 订到 S
else:
    Qₜ = 0        # 不订货
```

参数 (s, S) 通过仿真搜索优化。

### 4.5 最优动态规划

```
Bellman 方程：

Vₜ(I) = min_{Q ≥ 0} {  E[ Cₜ(I, Q, D) + V_{t+1}(max(I+Q-D, 0)) ] }

边界条件：
V_{T+1}(I) = -c × I    # 期末库存按成本价回收（或 0 如果不可回收）

其中：
  Cₜ(I, Q, D) = K×𝟙(Q>0) + c×Q + h×max(I+Q-D, 0) + p×max(D-I-Q, 0)
```

**求解方法**：对库存水平 I ∈ [0, S_max] 离散化，逆向递推求解。每个状态 I 枚举 Q，找到使期望总成本最小的 Q*。

### 4.6 为什么 (s,S) 是最优策略结构？

当固定订货成本 K > 0 时，最优策略不是「订到某个数」，而是：

1. **不订货区域**：当 I > s 时，库存足够，不订货
2. **订货到 S**：当 I ≤ s 时，订到 S

这看起来只是「两个数字」，但它背后有一个深刻的结论：**Scarf (1959) 证明了当成本函数是 K-凸时，最优策略一定是 (s,S) 形式的。**

```
成本
↑
│        不订货区域
│        ──────────→
│                    订货到 S
│    s←────→S
│    │         │
│    └──订货───┘
└──────────────────────────→ 库存水平 I
```

也就是说：你不需要算每个库存水平的最优订货量——只要找到 (s, S) 两个数字，策略就完全确定了。这就是 DP 告诉我们最有用的结论。

## ✅ 验证标准

1. **DP 成本 ≤ (s,S) 成本 ≤ (s,Q) 成本**：当 K>0 时，DP 是全局最优，(s,S) 是次优（但接近），(s,Q) 最差。这个排序必须成立。

2. **DP 策略的订货时机有 (s,S) 结构**：从 DP 策略中提取的订货决策应展现出「在某个阈值以下订货到某个水平」的模式（即使 DP 没有显式假设这种结构）。

3. **(s,S) 搜索的 Pareto 前沿合理**：s 越小（越不容易触发补货）则缺货越多；S 越大（补货量越大）则持有成本越高。最优 (s,S) 在缺货和持有之间平衡。

4. **所有仿真结果具有统计显著性**：每种策略运行足够多次（≥500 次），均值标准误 < 总成本的 2%。

5. **单期成本构成合理**：持有成本 ≈ 缺货成本 × (p/h 的比例)，订货频率 ≈ 每 T 期有固定订货成本 K 的次数。

## 7 关键洞察

1. **固定订货成本 K 是策略选择的决定性因素**：当 K=0 时，base-stock（每期订到 S）就够用了；当 K>0 时，必须用 (s,S) 来减少订货次数、分摊固定成本。这就是为什么小件便宜的商品（K 相对小）适合频繁补货，大件贵重设备（K 大）适合批量补货。

2. **(s,S) 用两个数字就近似了 DP 的全局最优**：DP 需要计算每个库存水平的最优决策（21 个状态），(s,S) 只需要 2 个参数——但成本只差 2.1%。这就是 Scarf 1959 定理的实践价值：**知道策略结构比知道精确数值更重要**。

3. **DP 的价值不仅是得到最优成本，更是告诉你什么是好的策略结构**：从 DP 结果中画出订货决策 vs 库存水平的图，你会发现它天然就是 (s,S) 形状——即使 DP 没有被告知要这样。这说明数学模型揭示的是问题的内在结构，而不只是算个数字。

---

## 8 延伸与变形

1. **K = 0 时的退化**：当 K=0，(s,S) 退化为 base-stock（Q = S - I，每期订到 S）。此时 (s,Q) 也退化为周期盘点 Q 策略。对比 K=0 和 K>0 两种情况。

2. **提前期 L > 0**：加入订单提前期（比如下单后 1 个月到货），库存动态方程变为 I_{t+L} = Iₜ + Qₜ - Σ_{i=0}^{L-1} D_{t+i}。这个扩展很实用。

3. **多商品联合补货**：多种商品共享一个固定订货成本（叫 truck 费用），这是「联合补货问题」（JRP），比单商品复杂得多。

4. **需求非稳态**：需求均值随时间变化（比如季节性药品），(s,S) 参数需要随时间调整。

5. **风险规避**：将目标从期望成本最小化改为 CVaR（条件风险值）最小化，最优策略仍然是 (s,S) 形式的吗？
