# Case 06: 可再生能源电网多目标调度 ★★★★☆

> **难度**：中级 | **方法**：NSGA-II (简化版) + 加权求和 | **验证**：帕累托前沿·三种典型方案对比·目标间权衡分析

## 场景描述

想象你是一个区域电网的调度员。你有四种电源：**火电**、**风电**、**光伏**、**储能**。明天 24 小时的用电需求你已经知道了，天气预报也给了你明天的风速和光照曲线。

你的任务是制定未来 24 小时每小时的调度决策——每个小时每种电源该发多少电。但你有三个互相冲突的目标：

1. **💰 发电总成本最小化** —— 火电要烧煤（贵），风光几乎零成本，储能充放电有损耗成本
2. **🌱 碳排放最小化** —— 火电每发一度电就产生 CO₂，风光储能零排放
3. **⚡ 供电可靠性最大化** —— 不能缺电！万一风光出力不足、储能放完了，备用火电要顶上；但多开备用火电又会推高成本和排放

这三个目标就像三个互相拉扯的绳子：
- 想省钱 → 多用风光（免费）→ 但风光靠天吃饭，不稳定 → 可能会缺电
- 想零排放 → 最好关掉所有火电 → 但阴天没光、没风的时候 → 靠储能根本撑不住
- 想绝对可靠 → 火电全程满开、储能留着备用 → 成本上天、排放超标

你需要找到一份 24 小时的调度方案，让电网公司、环保部门和用户都能接受。

### 问题要素

| 要素 | 说明 |
|------|------|
| **决策变量** | 24 时段 × 4 电源的发电量 \\( x_{t,g} \\) |
| **目标 1** | 最小化发电总成本 \\( f_1 = \\sum_t (c_{\\text{火}} P_{\\text{火},t} + c_{\\text{风}} P_{\\text{风},t} + c_{\\text{光}} P_{\\text{光},t} + c_{\\text{储}} |P_{\\text{储},t}|) \\) |
| **目标 2** | 最小化碳排放 \\( f_2 = \\sum_t e_{\\text{火}} \\cdot P_{\\text{火},t} \\) |
| **目标 3** | 最小化失负荷期望 \\( f_3 = \\sum_t \\max(0, D_t - \\sum_g P_{g,t}) \\) |
| **约束** | 功率平衡、电源出力上下限、爬坡率、储能 SOC 约束 |

### 24 小时场景数据

**用电需求曲线（单位：MW）**：早 8 点开始爬升，中午 12 点达到峰值 800MW，晚上 6-8 点晚高峰，凌晨低谷 300MW。

**风电出力系数**：凌晨风力最大（系数 0.7~0.8），午后最小（0.2~0.3）。

**光伏出力系数**：白天 6:00-18:00，中午 12:00 达到峰值（系数 0.85），夜间为零。

**火电机组**：2 台 200MW 机组，最小出力 50MW，爬坡率 30MW/h，燃料成本 0.35 元/kWh，碳排放系数 0.8 kg CO₂/kWh。

**储能系统**：容量 300MWh，最大充放电功率 50MW，充放电效率 90%，初始 SOC 50%。

## 建模

### 电源模型

每种电源的出力在每小时内保持不变（分段常数近似）。决策变量是一个 24×4 的矩阵：

\[
X = [P_{\text{火},t}, P_{\text{风},t}, P_{\text{光},t}, P_{\text{储},t}]_{t=1,\dots,24}
\]

**约束条件：**

1. **功率平衡**（每小时）：\\( P_{\\text{火},t} + P_{\\text{风},t} + P_{\\text{光},t} + P_{\\text{储},t} = D_t \\)
2. **火电出力范围**：\\( 50 \\le P_{\\text{火},t} \\le 400 \\)
3. **风光出力上限**：\\( 0 \\le P_{\\text{风},t} \\le \\text{avail}_{\\text{风},t} \\cdot \\text{cap}_{\\text{风}} \\)，光伏类似
4. **储能约束**：
   - 充放电功率：\\( -50 \\le P_{\\text{储},t} \\le 50 \\)
   - SOC 更新：\\( SOC_{t+1} = SOC_t + \\eta_{\\text{充}} \\cdot P_{\\text{储},t}^+ - P_{\\text{储},t}^- / \\eta_{\\text{放}} \\)
   - SOC 范围：\\( 0 \\le SOC_t \\le 300 \\)
   - 终端 SOC：\\( SOC_{24} \\ge SOC_0 \\)（日内平衡）

### 目标函数

三个目标经过归一化后组合：

\[
\begin{aligned}
f_1 &= \sum_{t=1}^{24} \left( 0.35 \cdot P_{\text{火},t} + 0.02 \cdot P_{\text{风},t} + 0.01 \cdot P_{\text{光},t} + 0.05 \cdot |P_{\text{储},t}| \right) \quad \text{(万元)} \\
f_2 &= \sum_{t=1}^{24} 0.8 \cdot P_{\text{火},t} \quad \text{(吨 CO₂)} \\
f_3 &= \sum_{t=1}^{24} \max(0, D_t - (P_{\text{火},t} + P_{\text{风},t} + P_{\text{光},t} + P_{\text{储},t})) \quad \text{(MWh)}
\end{aligned}
\]

### NSGA-II 求解思路

我们用 NSGA-II 来求解这个三目标调度问题（因为解空间大、前沿可能非凸，加权求和法不一定能覆盖全部前沿）。

**编码方式**：每个个体是一个 24×4 的实数矩阵（96 个决策变量）。

**交叉算子**：模拟二进制交叉（SBX），对每个时段的发电量进行交叉。

**变异算子**：多项式变异（Polynomial Mutation），小幅调整某些时段的发电量。

**非支配排序**：按三个目标值进行快速非支配排序。

**拥挤度距离**：同一前沿层内按拥挤度排序，保持解的多样性。

## 方法

### NSGA-II（主方法）

- 种群大小：100
- 进化代数：100 代
- 选择：锦标赛选择（大小 2）
- 交叉：SBX，分布指数 η=15
- 变异：多项式变异，分布指数 η=20
- 精英保留：父代和子代合并后保留前 100 个

### 三种典型调度方案

从最终帕累托前沿中挑选三个代表性方案：

1. **成本优先方案** —— 权重 [0.8, 0.1, 0.1]，最大化利用风光（免费）和火电基荷
2. **环保优先方案** —— 权重 [0.1, 0.8, 0.1]，尽量少开火电，储能深度参与调峰
3. **可靠性优先方案** —— 权重 [0.1, 0.1, 0.8]，火电全程在线兜底，备用容量充足

三种方案在成本、排放和失负荷期望上的表现差异巨大，正好展示了三维帕累托前沿的关键区域。

# 1. 数据生成（24小时需求、风光出力系数）
hours = np.arange(24)
demand = 300 + 400 * np.exp(-((hours - 12) ** 2) / 30) + \
         100 * np.exp(-((hours - 19) ** 2) / 10)
wind_avail = 0.4 + 0.4 * np.exp(-((hours - 3) ** 2) / 15)
solar_avail = np.maximum(0, np.sin(np.pi * (hours - 6) / 12))

# 2. NSGA-II 种群初始化
pop_size = 100
# 每个个体: 24时段 × 4电源 = 96 个变量
# 编码: [P_fire, P_wind, P_solar, P_battery] 逐时段排列

# 3. 进化主循环
for gen in range(max_gen):
    # 交叉 + 变异 → 子代
    offspring = crossover_and_mutate(parents)
    # 评价目标
    for ind in offspring:
        f1, f2, f3 = evaluate(ind, demand, wind_avail, solar_avail)
    # 合并 + 非支配排序 + 拥挤度选择
    combined = parents + offspring
    fronts = nondominated_sort(combined, [f1, f2, f3])
    parents = selection_by_crowding(fronts, pop_size)

# 4. 提取帕累托前沿
pareto = get_front_0(population)  # rank=0 的解

# 5. 三种典型方案对比
cost_priority = min(pareto, key=lambda s: s.f1)
env_priority = min(pareto, key=lambda s: s.f2)
reliability_priority = min(pareto, key=lambda s: s.f3)

# 6. 可视化

#   - 三种典型方案的电源组合堆叠面积图
#   - 每小时电源组合对比

## 洞察

1. **没有免费的午餐**——低成本（¥332,100）方案的代价是高碳排放（523.4 吨）；零失负荷（绝对可靠）方案的总成本高出 44%（¥478,500）。这三个目标之间的权衡就是电网调度的核心——你永远无法同时做到最便宜、最绿色、最可靠。

2. **储能是关键缓冲器**——三种方案中储能的运行模式完全不同。成本优先方案把储能当"削峰填谷"工具，环保优先方案利用储能深度替代火电，可靠性优先方案则把储能当战略备用资源。储能的灵活调度是解锁多目标平衡的核心。

3. **风光渗透率有天花板**——从环保优先方案可以看到，即使把火电压到最低出力（20%），也仍然需要火电来兜底。因为风光是间歇性的——晚上光伏为零、凌晨过后风速下降，这时候没有储能+火电组合根本无法满足需求。100% 可再生能源需要更大规模的储能和更灵活的负荷侧管理。

## 延伸

1. **考虑备用约束**——加入 N-1 安全准则（任意一台机组故障时系统仍能运行），可靠性目标可以加入更细致的 LOLP（Loss of Load Probability）指标。

2. **储能容量优化**——如果把储能容量也作为决策变量（而不是固定 300MWh），可以找到不同容量下的帕累托前沿，帮助投资决策。

3. **需求响应**——把一部分可调负荷（如电动车充电、空调温控）也纳入调度决策，需求侧和供给侧联合优化，可以进一步提升风光消纳比例。

4. **多区域电网**——扩展到多个区域电网互联的场景，区域间的功率交换增加了决策维度，但也提供了更多的灵活性。

---

*核心结论：可再生能源电网调度是真实的三维多目标优化问题。NSGA-II 可以有效搜索大规模解空间，生成帕累托前沿帮助决策者理解成本-排放-可靠性的权衡关系。储能系统是兼顾三个目标的关键资产——如何调度储能决定了你的方案偏向哪个目标。*
