## 场景

你是一家电阻制造厂的品质工程师。公司生产的电阻标称值是 **100Ω**，公差要求 **±5%**（即 95Ω~105Ω 为合格品）。

运营经理说："最近有几个批次的客户退货投诉，怀疑工艺有偏移。你帮我建立一个质量控制体系。"

你需要完成以下任务：

### 任务 1：分布拟合（使用案例1的方法）

抽取 1000 个电阻的阻值样本，判断它服从什么分布。

- 计算基本统计量（均值、标准差、偏度、峰度）
- 绘制直方图
- 判断：正态分布是否合适？
- 给出均值和方差的估计

### 任务 2：假设检验——判断工艺是否偏移（使用案例4的方法）

标称值 100Ω。用样本检验当前工艺均值是否偏离了目标值。

- 设定 H₀ 和 H₁
- 进行单样本 t 检验
- 给出结论：工艺是否有显著偏移？

### 任务 3：置信区间——过程能力指数 Cp/Cpk（使用案例2的区间估计）

过程能力指数是制造业的核心指标：

```
Cp = (USL - LSL) / (6σ)
Cpk = min[(USL - μ)/(3σ), (μ - LSL)/(3σ)]
```

- USL = 105Ω（上限），LSL = 95Ω（下限）
- 计算 Cp 和 Cpk
- 计算 Cp 的置信区间（用卡方分布）
- 判断过程能力等级（A、B、C、D 级）

### 任务 4：贝叶斯更新——来料批次更新先验（使用案例3的方法）

工厂又来了一批新的电阻材料，质检前你有先验信息（历史均值和方差）。抽检 30 个样品后，用贝叶斯方法更新对这批材料的品质估计。

- 设定合理的先验分布（使用 Normal-Inverse-Gamma 简化版）
- 计算后验均值和方差
- 对比：贝叶斯估计与 MLE 的区别

## 数学模型

### 分布拟合

检查数据是否符合正态分布：

```
H₀: 数据服从正态分布
H₁: 数据不服从正态分布

检验统计量（Shapiro-Wilk 近似用 QQ 相关性替代）：
r = corr(排序后的数据, 理论正态分位数)
```

### 假设检验

检验工艺均值是否等于 100Ω：

```
H₀: μ = 100（工艺正常）
H₁: μ ≠ 100（工艺偏移）

t 统计量：
t = (x̄ - 100) / (s / √n)

其中：
  x̄ = 样本均值
  s  = 样本标准差
  n  = 样本量（1000）
```

### 过程能力指数

```
Cp = (USL - LSL) / (6σ)     # 只考虑离散度，不考虑偏移
Cpk = min(USL - μ, μ - LSL) / (3σ)  # 同时考虑偏移和离散度

其中：
  USL = 105Ω（规格上限）
  LSL =  95Ω（规格下限）
  μ   = 样本均值
  σ   = 样本标准差
```

Cp 的置信区间（95%）：

```
P( Cp × √(χ²_{0.025, n-1}/(n-1)) < Cp_true < Cp × √(χ²_{0.975, n-1}/(n-1)) ) = 0.95
```

### 贝叶斯更新

```
先验：μ₀ ~ N(100, (5/√20)²)    # 等效于 20 个样本的经验
数据：x̄ = 样本均值，n = 30
后验均值 = (τ₀ × μ₀ + τ_data × x̄) / (τ₀ + τ_data)
  其中 τ₀ = n₀ / σ₀²（先验精度）
      τ_data = n / s²（数据精度）
```

## 求解方法

1. **数据生成**：用 Box-Muller 模拟 1000 个阻值（真实均值可能略偏 100.5Ω，模拟真实世界的微小偏移）
2. **分布拟合**：计算 QQ 相关性，判断正态性
3. **假设检验**：计算 t 统计量和 p 值，判断是否拒绝 H₀
4. **过程能力**：计算 Cp、Cpk，用卡方分布求 Cp 置信区间
5. **贝叶斯更新**：用精度加权平均更新后验参数
6. **可视化**：控制图（X̄-R 图）和过程能力图的文本输出

## 验证标准

1. ✅ 生成的阻值数据均值和标准差合理（均值 ≈ 目标值 ± 微小偏移，标准差约 1.5-2.0Ω）
2. ✅ 假设检验正确判断：当偏移 ≥ 0.5Ω 时 p < 0.05（拒绝 H₀）
3. ✅ Cp 置信区间包含真实 Cp 值（区间估计正确）
4. ✅ 贝叶斯后验均值介于先验和样本均值之间（加权平均性质）
5. ✅ Cpk < Cp（因为工艺有偏移，Cpk 比 Cp 更保守）

## 关键洞察

1. **Cp 和 Cpk 的区别：** Cp 衡量"过程能做到多好"，Cpk 衡量"过程实际做得怎样"。如果 Cp 很高但 Cpk 很低，说明过程精度够但偏了——调一下均值就行。如果 Cp 本身就低，那就需要改进工艺本身。

   **就像打靶**：Cp 是你的枪械精度（散布小不小），Cpk 是你瞄准后的成绩（有没有打偏）。枪准（Cp高）但瞄偏了（Cpk低）比枪不准（Cp低）要好解决得多——前者只需要校准准星，后者要换枪。

2. **质量管控的核心哲学：不是零缺陷，而是可控的缺陷率。** 3σ 过程（Cpk=1.0）的缺陷率约 0.27%，6σ 过程（Cpk=2.0）的缺陷率约 3.4 ppm（百万分之 3.4）。选哪个取决于成本——把 3σ 提升到 6σ 可能需要 10 倍的投入，而 0.27% 缺陷率在某些行业可以接受，在航空航天就不行。

3. **贝叶斯在质量管控中的实战价值：** 每批来料不需要从头检验。先验来自历史批次，抽检 30 个样品就可以更新参数。这大大减少了检验成本——对于每天进几十批料的工厂来说，这是真金白银的节省。
