## 🏗️ 项目结构

```
course-series/
├── 📈 01-概率论与数理统计/     # 数学基础：分布、估计、检验、蒙特卡洛
├── 🧮 02-低复杂度算法设计/     # 算法基础：DP、贪心、分治、二分
├── 📐 03-PDE物理方程求解/      # 连续优化：FDM、热传导、波动方程
├── 📊 04-运筹学基础与实战/     # 核心课程：LP、MIP、排队论、仿真
├── ♟️ 05-博弈论基础与实战/      # 策略分析：纳什均衡、拍卖、谈判
├── 📦 06-库存与供应链管理/     # 工业应用：EOQ、报童、牛鞭效应
├── 🎲 07-随机规划与鲁棒优化/   # 不确定性：两阶段、场景生成、DRO
├── 🎯 08-多目标优化/           # 多准则决策：NSGA-II、Pareto前沿
├── Makefile                   # 一键验证所有代码
├── requirements.txt           # Python 依赖
└── README.md                  # 本文件
```

### 每门课统一模板

```
XX-课程名/
├── README.md          # 术语速查 & 课程导览
├── 01-basics.md       # 基础概念
├── 02-*.md ~ 06-*.md  # 核心知识模块
├── 07-capstone.md     # 毕业项目说明
├── 08-appendix-*.md   # 附录（常见陷阱、ML交叉、推荐阅读）
├── prompt.md          # 课程生成提示词
└── code/
    ├── case01_*.py    # 教学案例（5-7 个）
    ├── capstone.py    # 毕业项目代码
    └── case*_cpp.cpp  # C++ 实现（部分课程）
```

## 🚀 快速开始

### 1. 环境准备

```bash
# 克隆仓库
git clone https://github.com/stwilliam503388-creator/course-series.git
cd course-series

# 安装依赖
pip install -r requirements.txt
```

### 2. 运行你的第一个案例

```bash
# 📈 概率论：蒙特卡洛仿真
python3 01-概率论与数理统计/code/case07_monte_carlo.py

# 📊 运筹学：元启发式求解 TSP
python3 04-运筹学基础与实战/code/case_metaheuristic_tsp.py

# ♟️ 博弈论：拍卖出价策略
python3 05-博弈论基础与实战/code/case04_auction.py

# 📦 供应链：牛鞭效应仿真
python3 06-库存与供应链管理/code/case05_bullwhip.py

# 🎯 多目标：NSGA-II 从零实现
python3 08-多目标优化/code/case07_nsga2.py
```

### 3. 一键验证全部代码

```bash
make list       # 列出所有代码文件
make python     # 运行所有 Python 案例
make cpp        # 编译并运行所有 C++ 代码
```

### 4. C++ 代码单独运行

```bash
g++ -O2 -std=c++11 -o /tmp/merge "02-低复杂度算法设计/code/case03_merge_cpp.cpp"
/tmp/merge              # 运行测试用例
/tmp/merge benchmark    # 性能基准测试
```

## 📐 设计原则

| 原则 | 说明 |
|------|------|
| 🧠 **先思考再动手** | 每个案例先分析问题，再写代码 |
| 🎯 **简单至上** | 用最简洁的方式讲清楚核心概念 |
| 🔪 **手术刀式修改** | 代码改动精准，不引入多余复杂度 |
| 🏹 **目标驱动** | 每个案例都有明确的验证标准和预期结果 |

> 灵感来源：**Karpathy 四原则** — 先思考、简单至上、手术刀式修改、目标驱动执行

### 案例设计模式

每个教学案例遵循统一的 **7 步结构**：

```
场景描述 → 数学建模 → 方法选择 → 代码实现 → 结果分析 → 验证标准 → 延伸思考
```

### 依赖层级

| 层级 | 依赖 |
|------|------|
| 核心案例 | Python 标准库 + `numpy` |
| 进阶案例 | + `scipy` |
| 建模案例 | + `pyomo`（需安装求解器） |
| 仿真案例 | + `simpy` |
